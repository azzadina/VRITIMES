# Style reference (supplied in chat 2026-11-12 — image not saved as file)

Two reference grids were pasted into chat. They are STYLE ONLY — no text, brand names, people or stickers copied.

## Ref A — "hot take" social agency grid (primary)
- 3 tile types in checkerboard: royal-blue typographic, pale-blue typographic, photo tile with headline overlay.
- Headlines: heavy rounded geometric sans, lowercase, very tight leading, centred, huge; 1–3 words in lime (on blue) or navy/blue (on pale).
- Small navy pill tags with handwritten-style white text, slightly rotated, overlapping headline edges.
- Round logo "stamp" badge top-right, cropped by the edge.
- Lime oval sticker with slogan bottom-left, cropped by the edge.
- Photo frames hung on a string with clips; reel icon top-right.

## Ref B — agency carousel grid (secondary accents)
- Bottom footer bar (rounded top corners) with website pill.
- Checklist rows as rounded pills with check icons.
- Lime/black wavy ribbon crossing the canvas.
- Highlight box behind key words; script/italic accent word.

## How we apply it for VRITIMES
- Ref A layout system for all covers; Ref B footer bar + checklist pills on PROMO and CTA slides; wavy lime ribbon as occasional accent (≤10% area).
- Photo tiles use labelled placeholder frames or flat illustrations (no stock / no real people).
